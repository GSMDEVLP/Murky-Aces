# Interaction

Единая система взаимодействия. Каждая цель реализует `IInteractionTarget` и предоставляет стабильные экземпляры `IInteractionAction`. Один и тот же путь используется для подбора, переключателей, станций, GPS, заряжания, установки, снятия, сварки и люка.

## Слои

| Папка | Ответственность |
|---|---|
| Abstractions | Цель, действие, актор, ввод, поиск, область доступа и переноска |
| Domain | Режим Press/Hold, идентификаторы, описание действия, состояние выбора и carry-сессия |
| Application | Получение доступных действий, меню игрока, запуск, удержание, отмена |
| Infrastructure | Unity Physics, ссылки коллайдеров на цель, базовые MonoBehaviour целей, подбор и физика предмета |
| Presentation | HUD и представление меню; игровых команд здесь нет |
| Sandbox | Существующие демонстрационные цели сцены |

Новые Domain/Application-типы взаимодействия не зависят от Unity, Input System, UI, Exterior или станций. Ввод поступает через `IInteractionInput`, который реализует существующий `PlayerIntentBuffer`.

## Контракт

- `IInteractionTarget.CollectActions` добавляет действия в переданный список и не очищает его. Обработчики должны сохранять экземпляры действий между кадрами.
- `InteractionActions.CollectAvailable` очищает рабочий список, собирает действия и фильтрует недоступные.
- Идентификаторы действий уникальны внутри одной цели. Для простой цели используется `Primary`; у крепления — `Install`, `Remove`, `Weld`.
- `Revision` цели и действия обозначает поколение их lifetime. `InteractionInfo.Revision` — версию игрового контекста, например ячейки или положения экипажа.
- Все три версии проверяются при выборе/удержании. Также проверяются идентичность обработчика, prompt, режим и длительность.
- `Begin` резервирует операцию, `Complete` завершает, `Cancel` освобождает. Конкретные команды повторно проверяют свои условия и отвечают за откат.
- `SingleActionInteractionTarget` — обычная реализация цели с одним действием, а не отдельный старый путь выполнения.
- Приём предмета использует `IHoldableItem`, без зависимости от взаимодействия.

## Поведение игрока

Одно доступное действие выполняется через E, с существующим режимом Press/Hold. Несколько действий открывают меню. Управление меню: W/S или стрелки, E для подтверждения, Esc для отмены. Открывающее нажатие E должно быть отпущено до подтверждения. Для выбранного Hold требуется новое удержание E.

Меню принадлежит конкретному `PlayerInteraction`. На время выбора подавляется движение, обзор и станционные команды игрока; симуляция мира продолжается. Смена цели, доступных действий, lifetime, области доступа или контекста ввода отменяет выбор. Закрытие меню восстанавливает обработку обычного ввода, сохраняя остальные ограничения игрока.

Панель выбора использует существующий uGUI Canvas и TMP. Это текстовый список с навигацией через Input System, без мышиных Button/EventSystem-событий. Подсказки клавиш сейчас соответствуют клавиатуре.

## Люк и Exterior

`Tank/Interior/Infrastructure/TankHatchInteractionTarget` объединяет проход и крепление крышки. Оба коллайдера ссылаются на одну цель:

- пустые руки, крышка не приварена: проход и снятие;
- пустые руки, крышки нет или она приварена: только проход;
- подходящая деталь или аппарат в руках: доступная операция Exterior;
- операция Exterior с предметом недоступна: остаётся обычный проход.

Установка и сварка крышки не управляют доступностью прохода. Снятие до сварки использует прежнюю команду Exterior. Крепление крышки находится под `Turret_Yaw`.

Preview получает данные через `Exterior/Abstractions/IExteriorPlacementPreviewSource`. Его реализуют обычное крепление и общая цель люка; presenter не зависит от конкретного MonoBehaviour крепления.

## Проверка

Из корня проекта:

```powershell
dotnet run --project Tests/Interaction/Interaction.Core.Tests.csproj --configuration Release
```

Это проверки настоящего C#-ядра и команд Exterior без запуска Unity. Нативные типы Transform/Vector3 в тестовом проекте представлены только пустыми объявлениями для компиляции портов, физика не имитируется. Unity-сборка, ссылки префабов, физический поиск и игровые циклы дополнительно проверены в редакторе; отчёт — `Markdown/UNIFIED_INTERACTION_IMPLEMENTATION.md`.
