# Interaction regression checks

Запуск из корня Unity-проекта:

```powershell
dotnet run --project Tests/Interaction/Interaction.Core.Tests.csproj --configuration Release
```

Тестовый проект компилирует исходники общего ядра Interaction и команд Exterior напрямую из Assets. Пакеты тестовых библиотек не требуются; код возврата 0 означает успех, 1 — провал.

Проверяются Press/Hold, выбор действия, защита от открывающего нажатия, отмена, независимость двух игроков, смена контекста/цели/обработчика/поколения, повторное завершение, реентерабельность и откаты команд установки/снятия.

`UnityTypeStubs.cs` содержит только имена нативных типов в сигнатурах carry-порта, без поведения. Физика, UI и сериализация проверяются отдельно в Unity. Этот проект находится вне Assets и не попадает в сборку игры.
